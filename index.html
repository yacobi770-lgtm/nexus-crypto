📋 איך להפעיל Auto-Trade
שלב 1 — צור API Key בבורסה:
• Binance: פרופיל → API Management → Create API → סמן Futures Trading
• Bybit: פרופיל → API → Create API → סמן Trade
• OKX: פרופיל → API → Create V5 API → Futures
• MEXC: פרופיל → API Management → Create API

שלב 2 — הגדר ב-Render Environment Variables:
• AUTO_TRADE_ENABLED = true
• AUTO_TRADE_EXCHANGE = binance (או bybit/okx/mexc)
• AUTO_TRADE_TESTNET = true (בדיקה!) / false (אמיתי)
• AUTO_TRADE_RISK_PCT = 5
• המפתחות של הבורסה שבחרת

שלב 3 — בדוק חיבור לחיצה על "בדוק חיבור"
שלב 4 — הפעל סריקה ← האתר יסחר אוטומטית!
